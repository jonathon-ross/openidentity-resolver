# OpenIdentity Resolver 0.1.0

First reference resolver release for OpenIdentity Protocol v0.1.1.

## Compatibility

- OpenIdentity Protocol: v0.1.1
- openidentity-java: v0.1.2
- Java: 21+
- PostgreSQL: 17 tested

## Highlights

The resolver persists canonical immutable identity history and resolves both current and exact historical states. It accepts and verifies all five Protocol v0.1.1 operations through the released Java SDK.

This release demonstrates OI-003 historical credential authority end-to-end: a credential issued under one assertion key remains verifiable after assertion authority changes because its signed issuanceStateHash resolves the exact historical IdentityState that authorized the issuing key.

## Verification

The release gate runs formatting checks, the complete Maven build, PostgreSQL-backed integration tests, Javadoc generation, and clean-worktree checks using an isolated disposable Compose PostgreSQL service.
